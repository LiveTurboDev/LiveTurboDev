### Возможности

- ⚡ Высокая скорость и стабильное соединение
- 🔒 Приватность: не храним логи трафика, без рекламы и трекеров
- 🌍 Выбор локаций и сервер «АВТОВЫБОР» — ноду подбираем на своей стороне
- 📱 Подписка, устройства, баланс и поддержка прямо в приложении
- 🎯 На компьютере — выбор программ: какие идут через VPN, а какие напрямую

### Windows

Обычный установщик, 24 МБ. Весь трафик компьютера идёт через VPN, либо только выбранные программы.
Кабинет внутри приложения, вход через Google, Яндекс, почту или Telegram. Обновляется само:
«Настройки → Проверить обновление».

Установщик пока без сертификата подписи — Windows покажет окно SmartScreen, нужно нажать
«Подробнее» → «Выполнить в любом случае». Контрольные суммы лежат рядом с каждым релизом.

### Протоколы

Клиент построен на официальном ядре **Xray-core**: VLESS, VMess, Trojan, Shadowsocks, Reality, XHTTP.
